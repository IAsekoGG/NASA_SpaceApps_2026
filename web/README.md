# Вебзастосунок «Каховка крізь перешкоди»

Статичний сайт: `index.html`, `assets/` (CSS, JS, тексти англійською в `i18n.js`, без збірки), `data/app.json`, `layers/` (PNG, ~22 МБ).
Бібліотека карти — MapLibre GL 4.7.1 з unpkg, підкладки Esri без ключа й без підписів (тіньовий рельєф, супутник).

Шари на кожну дату: `<дата>_raw.png` (сирий HH з тонуванням осередків RFI за відношенням R / сигнал),
`<дата>_clean.png` (після корекції), `<дата>_mask.png` (штрихування: RFI 2–4 × сигнал — знижена якість,
> 4 × — пошкоджено). Пороги й класи поверхні — у `tools/export_web.py`.

## Оновити дані

```bash
python -I tools/eval_rfi_clean.py      # чистка + стеки
python -I tools/run_change_rfi.py      # тест змін
python -I tools/export_web.py          # шари й app.json для сайту
```

RFI показано лише як характеристику якості даних (тонування й маска); джерела перешкод не локалізуються (район бойових дій).

## Локально

```bash
python -m http.server 8765 --directory Project/web
```

## Викласти

Будь-який статичний хостинг. Потрібно скопіювати вміст `Project/web/` (крім `README.md`) у корінь сайту.
Шляхи всередині відносні, тож сайт працює і в корені домену, і в підтеці.
